# Вызов к доске

Программа для случайного вызова студентов к доске на паре: отметка присутствующих,
вызов «по кругам», озвучивание ФИО через динамики и сохранение итогов пары в Excel.

## Быстрый старт

1. Установите **Python 3.8+** с [python.org](https://www.python.org/downloads/)
   (при установке отметьте **Add python.exe to PATH**). Подойдёт и Anaconda.
2. Отредактируйте `students.txt`: одно ФИО на строку.
3. Дважды щёлкните **`Start.bat`**.

При первом запуске `Start.bat`:

- находит Python;
- создаёт виртуальное окружение `.venv` в папке программы (системный Python не засоряется);
- проверяет библиотеки из `requirements.txt` и устанавливает недостающие через `pip`
  (нужен интернет, только в первый раз);
- запускает программу.

Последующие запуски занимают пару секунд: если всё установлено, ничего не скачивается.

Запуск вручную: `python main.py` (после `pip install -r requirements.txt`).

## Работа на паре

| Шаг | Что делать |
|---|---|
| 1. Перекличка | Щёлкните по колонке **«Присутствует»** у пришедших (или дважды по строке, или Пробел). Кнопка **«Все присутствуют»** отмечает всех сразу. |
| 2. Опоздавшие | Отмечайте их так же в любой момент пары. Время отметки запоминается. |
| 3. Сколько вызвать | Поле **«Сколько вызвать»**, по умолчанию 4. |
| 4. Вызов | Кнопка **«Вызвать»** или клавиша **F5**. |
| 5. Задание | После вызова курсор встаёт в поле **«Задание»**, впишите короткое описание. |
| 6. Сохранение | **«Сохранить результат пары в Excel…»**, по умолчанию файл кладётся в папку `results`. |

Цвета в списке: **жёлтый**: сейчас у доски; **зелёный**: уже выходили;
**серый**: отсутствуют; **оранжевый текст**: опоздали.

### Как выбираются студенты

- Вызываются только присутствующие.
- Сначала случайно выбираются те, кто **ещё ни разу не выходил** на этой паре.
- Когда вышли все, начинается **второй круг** (потом третий и т. д.).
  Номер круга виден над списком.
- На стыке кругов программа старается не вызывать тех, кто только что стоял у доски.
- Опоздавший сразу попадает в число невызванных, поэтому будет вызван в первую очередь.
- Если присутствующих меньше, чем нужно вызвать, вызываются все.

### Озвучка (Silero TTS)

После вызова программа произносит «К доске выходят: …». Кнопка **«Повторить озвучку»**
повторяет фразу, галочка **«Озвучивать ФИО»** отключает звук.

Основной движок — **[Silero TTS](https://github.com/snakers4/silero-models)**, нейросетевой
русский синтез речи. Он работает **без интернета**, сам расставляет ударения и звучит почти
как живой человек.

- **Первый запуск.** `Start.bat` ставит `torch` (несколько сотен МБ, установка займёт
  несколько минут). При первом старте программа скачивает голосовую модель (~100 МБ)
  в папку `models`. Пока модель скачивается и загружается, ФИО читаются голосом Windows.
  Справа от выбора голоса видно состояние: «Silero загружается…» или «Silero готов».
- **Голос.** Выбирается в списке **«Голос Silero»**: xenia, kseniya, baya (женские),
  aidar, eugene (мужские). При выборе звучит «Проверка голоса». Выбор запоминается.
- **Без задержек.** После загрузки списка программа в фоне заранее озвучивает все ФИО,
  поэтому при нажатии «Вызвать» звук начинается сразу.
- **Ударения.** Если Silero ошибается в фамилии, поставьте в `students.txt` знак `+`
  перед ударной гласной: `Кузнец+ов Дм+итрий Игоревич`. На экране и в Excel
  `+` не отображается.
- **Проверка голоса отдельно от программы:** `TestVoice.bat` (можно указать голос:
  `TestVoice.bat baya`). Он показывает версии, время синтеза и проигрывает фразу.

**Лицензия моделей Silero — CC BY-NC (только некоммерческое использование).**

**Запасная озвучка.** Если `torch` не установился или модель не скачалась, программа
работает как раньше: через `pyttsx3` и голоса Windows, а если и это не вышло, через
System.Speech в PowerShell. Для них нужен русский голос Windows: *Параметры → Время и
язык → Речь → Добавить голоса → Русский*. Чтобы принудительно отключить Silero, впишите
`"use_silero": false` в `settings.json`.

### Результат в Excel

Файл `Пара_ГГГГ-ММ-ДД_ЧЧ-ММ.xlsx`, три листа:

- **Студенты**: ФИО, присутствовал, время отметки, опоздал, сколько раз выходил, задания;
- **Вызовы**: по строке на каждого вызванного: № вызова, время, ФИО, задание;
- **Итоги**: дата, сколько было, отсутствовало, опоздало, число вызовов.

## Список студентов

Список меняется от пары к паре, поэтому его можно:

- править в `students.txt` (кодировка UTF-8 или Windows-1251, пустые строки и строки
  с `#` пропускаются);
- загрузить любой другой файл кнопкой **«Загрузить список…»**: `.txt`, `.csv` или `.xlsx`
  (ФИО в первом столбце; заголовок «ФИО» допускается).

Программа запоминает последний загруженный список и при следующем запуске перечитывает его
с диска. Кнопка **«Новая пара»** тоже перечитывает файл и сбрасывает отметки и вызовы.
При закрытии окна, загрузке списка или начале новой пары программа предложит
сохранить несохранённые результаты.

Опоздавшим считается студент, отмеченный позже чем через 10 минут после первой отметки
на паре. Порог меняется в `student_caller/config.py` (`LATE_MINUTES`).

## Структура проекта

```
StudentCaller/
├── Start.bat               запуск: проверка и установка зависимостей
├── main.py                 точка входа
├── TestVoice.bat           проверка голоса Silero
├── requirements.txt        библиотеки (openpyxl, pyttsx3, torch, numpy)
├── students.txt            список студентов
├── readme.md
├── tools/ensure_deps.py    проверка и установка библиотек (для Start.bat)
├── tools/test_voice.py     проверка Silero (для TestVoice.bat)
└── student_caller/
    ├── config.py           константы и пути
    ├── models.py           модель пары: Student, CallRecord, Lesson
    ├── selection.py        алгоритм случайного выбора «по кругам»
    ├── roster.py           загрузка списка из txt/csv/xlsx
    ├── speech.py           озвучка: Silero + запасные pyttsx3 и PowerShell
    ├── exporter.py         сохранение в Excel (openpyxl)
    ├── settings.py         настройки между запусками (settings.json)
    └── gui.py              интерфейс на tkinter
```

Архитектура разделена на слои: **данные и логика** (`models`, `selection`) не зависят
от интерфейса, **ввод-вывод** (`roster`, `exporter`, `speech`, `settings`) изолирован
в отдельных модулях, **интерфейс** (`gui`) только связывает их.
Поэтому логику легко проверить тестами, а интерфейс заменить.

Во время работы создаются: `.venv/` (библиотеки), `models/` (модель Silero), `results/` (файлы Excel),
`settings.json` (последний список, число вызываемых, размер окна), `error.log` (только при ошибках).

## Библиотеки

Все свободно распространяемые, ставятся через `pip`:

- **openpyxl** (MIT): запись `.xlsx`;
- **pyttsx3** (MPL-2.0): запасной синтез речи голосами Windows; сам подтягивает `comtypes` и `pywin32`;
- **torch** (BSD) и **numpy** (BSD): нужны для Silero. Помечены в `requirements.txt` как
  `# optional`: если они не установятся, программа всё равно запустится с голосом Windows.

`tkinter` входит в стандартный Python.

## Возможные проблемы

| Проблема | Решение |
|---|---|
| «Не найден Python» | Установите Python с отметкой *Add python.exe to PATH* или перезапустите компьютер после установки. |
| Не удаётся установить библиотеки | Проверьте интернет. Можно удалить папку `.venv` и запустить `Start.bat` снова. |
| Не сохраняется Excel | Файл с таким именем открыт в Excel: закройте его. |
| «Silero недоступен» | Запустите `TestVoice.bat` и посмотрите ошибку. Чаще всего не установился torch (запустите `Start.bat` ещё раз) или не скачалась модель (нужен интернет при первом запуске). |
| Нет звука или ФИО читаются по-английски | Это запасной голос Windows: установите русский голос (см. «Озвучка»), проверьте громкость. |
| Окно не открылось | Посмотрите `error.log` в папке программы. |
